# 📚 BookNest - Modern Library Management System

A responsive desktop Library Management System built with Python, CustomTkinter, and MySQL.

## ✨ Features
- **Multi-Tier User Portals**: Dedicated access for Students, Librarians, and Superadmins.
- **Automated Borrowing Rules**: 3-book limit enforcement, single-copy restrictions, and overdue detection.
- **Admin Management**: Book inventory CRUD operations and user management.
- **Live Statistics**: Visual analytics on total circulation and popular books.

## 🛠️ Tech Stack
- **Frontend**: Python (CustomTkinter)
- **Database**: MySQL
- **Security**: SHA-256 password hashing

## 🚀 Setup & Installation
1. Clone the repository or download the source code.
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt```
   ### Database Setup
1. Open MySQL Workbench or your terminal.
2. Run the queries inside `schema.sql` to initialize the database tables and default admin account.
